"# Proyecto de Entornos de Desarollo - UD01" 

## Descripción
Repositorio de prácticas de la UD01 para el aprendizaje de control de versiones con Git y GitHub en el módulo de Entornos de Desarrolo.

## Comando esenciales aprendidos
* `git status`: Consulta el estado del directorio de trabajo.
* `git add`: Prepara archivos para el proximo commit.
* `git commit`: Guarda una instantanea con mensaje descriptivo.
* `git switch -c`: Crea y cambia a una nueva rama.
* `git merge`: Fusiona ramas.
